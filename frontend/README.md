# Knosis Frontend

Фронтенд-приложение платформы управления знаниями **Knosis**.

## Стек технологий и сохранённые зависимости

Проект использует React и TypeScript для работы с графами знаний, онтологиями и документацией:

- **React 18** + **TypeScript** — основа интерфейса и типобезопасность.
- **Vite 6** — dev-сервер и сборка.
- **Tailwind CSS 4** — стилизация интерфейса с поддержкой тёмной темы.
- **`@xyflow/react` (React Flow)** — интерактивный движок для визуализации и редактирования узлов и связей онтологии и графа знаний (Apache AGE).
- **`@mdxeditor/editor`** — полнофункциональный WYSIWYG / Markdown редактор для работы с документацией и источниками знаний.
- **`react-router-dom` (v7)** — клиентская маршрутизация.
- **`lucide-react`** — иконки интерфейса.
- **`radix-ui`** — доступные UI-примитивы.

## Запуск разработки

Из корня репозитория:
```bash
# Запуск фронтенда в dev-режиме (http://localhost:5173)
npm run dev:frontend

# Или напрямую в директории frontend
cd frontend
npm run dev
```

## Сборка

```bash
# Сборка из корня
npm run build --workspace frontend

# Или внутри директории frontend
cd frontend
npm run build
```

## План архитектуры нового подхода

1. **Интеграция с PostgreSQL + Apache AGE**:
   - Получение графовых данных через бэкенд (Cypher-запросы).
   - Отображение вершин (Labels, Properties) и ребер (Edges) через `@xyflow/react`.
2. **Онтология**:
   - Визуальное моделирование классов сущностей и типов отношений.
3. **Редактор документов**:
   - Подготовка и разметка неструктурированных текстов через `@mdxeditor/editor` для извлечения сущностей в граф.
